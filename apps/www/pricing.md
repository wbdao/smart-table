# Pricing

SmartTableJS is **100% open source** under the MIT license. The core, all
framework adapters, the Web Component, plugins, telemetry and devtools are free
to use commercially — forever.

| Plan                | Price         | Who it's for                                         |
| ------------------- | ------------- | ---------------------------------------------------- |
| Open Source         | **$0**        | Everyone — MIT, no strings attached                  |
| Enterprise support* | request quote | SLA, priority fixes, migration help, custom adapters |

> \* _Enterprise support tiers are a placeholder — the team is defining
> guarantee levels, response-time SLAs and workshop offerings. No payment is
> accepted today; this page will be updated before the general-availability
> release._

## What's never paywalled

- The grid engine and all `@smart-table/*` packages.
- Bug fixes and security patches.
- Community support via GitHub Discussions and issues.

If your organization needs guarantees beyond the community, reach out on
[GitHub Discussions](https://github.com/smart-table-js/smart-table/discussions).
