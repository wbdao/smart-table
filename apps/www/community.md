# Community

SmartTableJS is a community project. Join the conversation — everyone is
welcome under our [code of conduct](https://github.com/smart-table-js/smart-table/blob/main/CODE_OF_CONDUCT.md).

## Get answers

- **GitHub Discussions** — Q&A, ideas, and show-and-tell:
  [discussions](https://github.com/smart-table-js/smart-table/discussions)
- **Issues** — bug reports and feature requests
  ([templates](https://github.com/smart-table-js/smart-table/issues/new/choose))

## Contribute

- Read
  [CONTRIBUTING.md](https://github.com/smart-table-js/smart-table/blob/main/CONTRIBUTING.md)
  — setup, conventions, changesets and the PR checklist.
- Good first issues are labelled `good first issue`.
- Report vulnerabilities privately via
  [GitHub Security Advisory](https://github.com/smart-table-js/smart-table/security/advisories/new)
  — see [SECURITY.md](https://github.com/smart-table-js/smart-table/blob/main/SECURITY.md).

## Show & tell

Built something great with SmartTableJS? Share it in the _Show & tell_
Discussion category — it feeds the official blog and case studies.

## Supporting the project

- ⭐ Star the repo — reach matters.
- Report issues with reproductions instead of only anecdotes.
- Sponsor ongoing maintenance via GitHub Sponsors _(coming soon)_.
