# Roadmap

We are midway through **Phase 7 — beta release, adoption and enterprise
integrations**. The full strategy lives in
[ROADMAP.md](https://github.com/smart-table-js/smart-table/blob/main/ROADMAP.md).

## Now: Phase 7 (in progress)

- 7.1 Beta release prep — governance, templates, `v0.9.0-beta` strategy
- 7.2 This website
- 7.3 AG Grid migration adapter (`@smart-table/ag-compat`)
- 7.4 TanStack Query / Router integration (`@smart-table/tanstack`)
- 7.5 Telemetry (`@smart-table/telemetry`)
- 7.6 Developer overlay (`@smart-table/devtools`)
- 7.7 Collaboration foundation — transport/sync/conflict abstractions
- 7.8 Charts foundation — Chart.js / ECharts / ApexCharts adapters
- 7.9 Security foundation — roles, permissions, policies
- 7.10 API stability review → `API_STABILITY.md`
- 7.11 Performance certification → `PERFORMANCE_REPORT.md`
- 7.12 v1.0 readiness → `RELEASE_CHECKLIST.md`

## Next

- Public beta cut: **v0.9.0-beta**.
- **v1.0.0** — API freeze, migration guides, accessibility + security audit.

## After v1.0 (backlog)

- Real-time collaboration implementations (WebSocket / SignalR / Yjs / CRDT).
- Charts adapter implementations.
- SSR helpers, i18n bundle, enterprise theming pack.

Track progress on the [GitHub milestone](https://github.com/smart-table-js/smart-table/milestones).
